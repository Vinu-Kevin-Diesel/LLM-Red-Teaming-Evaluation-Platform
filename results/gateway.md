# Guardrail gateway

Requests go through `POST /v1/chat/completions` on the gateway: input guard → upstream model → output guard. *Stopped at input* never reaches the model; *stopped at output* means the model answered and the reply was replaced. For safe prompts, any stop is a false block. Generated by `python -m llm_eval_forge.serve.replay report`; full replies stay local.
