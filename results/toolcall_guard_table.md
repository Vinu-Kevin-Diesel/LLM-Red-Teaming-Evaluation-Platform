# Tool-call guard: offline evaluation on AgentDojo traces

`toolcall-guard-A` judges each proposed tool call (goal, calls so far, last tool output, proposed call). Trained on the workspace, travel and slack suites; **banking is held out entirely** (unseen tools and data). Threshold 0.05 tuned on validation. Positive = attacker-induced call. FPR = share of legitimate calls that would be blocked. Generated by `python -m llm_eval_forge.agent.toolcall_eval`.
